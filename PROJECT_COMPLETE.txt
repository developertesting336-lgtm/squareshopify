QUICK START (5 STEPS)
================================================================================

Step 1: Install Dependencies
  npm install

Step 2: Create Configuration
  cp .env.example .env

Step 3: Add Credentials
  Edit .env with:
  - Shopify Client ID
  - Shopify Client Secret
  - Shopify Store URL
  - Square Access Token
  - Square Application ID
  - Square Application Secret

Step 4: Test Locally
  npm run dev
  curl http://localhost:8080/health

Step 5: Deploy
  Follow DEPLOY.md for:
  - Vercel (recommended)
  - Heroku
  - AWS
